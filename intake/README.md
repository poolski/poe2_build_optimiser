# Intake

Raw inputs, specifications, and source documents that inform the project.

This folder holds:
- **Vision sources** — business specs, feature requests, user feedback that shaped the roadmap
- **Design specs** — upstream requirements or constraint definitions
- **Reference materials** — external documents or standards that guide implementation

Files here are the *sources*; they are synthesized into curated docs elsewhere:
- `docs/VISION.md` — the synthesized project direction
- `docs/decisions/` — the architecture choices
- `docs/` — all other curated documentation

## What goes here

- Raw specs or feature briefs (before synthesis into VISION)
- External API contracts or data schemas
- User feedback summaries or requirements
- Design sketches or wireframes from stakeholders
- Anything that influenced a major decision, in its original form

## What doesn't

- Code (see `src/`, `packages/`)
- Curated documentation (see `docs/`)
- Intermediate working notes (keep in a local branch or private notes, not here)
