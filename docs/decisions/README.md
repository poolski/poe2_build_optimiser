# Architecture Decision Records

Records of significant decisions and their rationale. These are the "why" behind major choices — useful context for future maintainers and for understanding trade-offs.

## Format

Each ADR is a markdown file named `ADR-NNN-title.md` with:
- **Status** — Accepted / Rejected / Superseded / Deprecated
- **Context** — the situation that prompted the decision
- **Decision** — the choice and why it matters
- **Consequences** — what follows from this choice; trade-offs
